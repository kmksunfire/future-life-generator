Drop-in 3D models for Trail Run
1. Put .glb files in this folder (for example kart.glb, kiteboard.glb, yvonne.glb, finn.glb, toby.glb).
2. Rename models-example.json to models.json and keep only the lines for files you added.
3. Each model replaces the built-in one and is scaled to the same size.
   "rotY": 180 turns a model around if it faces backwards. "includesRiders": true hides Finn and Toby
   if the kart model already has them sitting in it.
